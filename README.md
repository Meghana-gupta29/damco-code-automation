# QA Orchestrator

Agentic QA workflow for [full-stack-fastapi-template](https://github.com/fastapi/full-stack-fastapi-template):
AI agents plan, write, triage and fix; a Python CLI runs the tests, enforces human approval gates, and produces a
release-readiness verdict, report, dashboard and email.
