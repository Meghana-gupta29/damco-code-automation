feat(items): search items by title
https://github.com/Meghana-gupta29/damco-code-opensource/pull/1 · branch feature/item-search · risk: medium

GET /api/v1/items/ gains an optional case-insensitive `search` parameter that filters by title (icontains, autoescaped) and is combined with the existing owner filter. The previous separate superuser/non-superuser branches were refactored into a single shared filter list, with the count and the page both using the same filters. The Items page gets a search input (data-testid=item-search) that re-queries the API and shows 'No items match your search' when nothing matches. The refactor touches the owner-scoping logic, so there is some risk of a regression in access control.
